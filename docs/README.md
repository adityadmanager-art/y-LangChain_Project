# LangChain Project — Documentation

Welcome to the official documentation for this LangChain learning repository.

## Overview

This repository is a collection of small, focused projects built using [LangChain](https://www.langchain.com/) — a powerful framework for developing applications powered by large language models (LLMs). Each project demonstrates a specific use case or concept, making this repository both a learning resource and a growing portfolio.

## Features

- 🔗 Hands-on LangChain project examples
- 📂 Modular folder structure — each project is self-contained
- 📝 Clear documentation and setup instructions
- 🚀 Beginner-friendly with room to grow

## Projects

| Project | Description |
|---|---|
| `Restaurant_Learning` | Demonstrates LangChain basics through a restaurant-themed workflow |
| `Restaurant_name_menu` | Generates restaurant names and menus using LLM chains |

# LangChain Project

A collection of hands-on projects built with [LangChain](https://www.langchain.com/) — exploring how to build intelligent, LLM-powered applications using Python.

## Projects

| Folder | Description |
|---|---|
| [`Restaurant_Learning`](./Restaurant_Learning) | Demonstrates LangChain basics through a restaurant-themed workflow |
| [`Restaurant_name_menu`](./Restaurant_name_menu) | Generates restaurant names and menus using LLM chains |

Each folder contains its own code and README for a specific use case.
